Builds one service image, tags it with an immutable commit tag plus any
moving tags, and attaches OCI provenance labels.

<dl>
  <dt><code>name</code> (required)</dt>
  <dd>Image name, e.g. <code>msme-backend</code>.</dd>

  <dt><code>tag</code> (required)</dt>
  <dd>The immutable tag. The pipeline passes the git short SHA.</dd>

  <dt><code>context</code></dt>
  <dd>Build context directory. Defaults to <code>name</code>.</dd>

  <dt><code>dockerfile</code></dt>
  <dd>Path to the Dockerfile. Defaults to <code>&lt;context&gt;/Dockerfile</code>.</dd>

  <dt><code>alsoTag</code></dt>
  <dd>List of extra moving tags, e.g. <code>['dev']</code>.</dd>

  <dt><code>registry</code></dt>
  <dd>Registry prefix for a pushed image, e.g. <code>ghcr.io/acme</code>.
      Omitted for local builds into the minikube daemon.</dd>
</dl>

Returns the fully qualified primary image reference.

<pre>
def image = dockerBuildAndTag(
  name:    'msme-backend',
  tag:     env.GIT_SHA,
  alsoTag: ['dev'],
)
</pre>
